# docs/PDPA.md
## นโยบายการประมวลผลข้อมูลส่วนบุคคล (PDPA)

### ข้อมูลส่วนบุคคลที่เก็บรักษา
| ประเภทข้อมูล | ทำไมเก็บ | ใครเห็น | ระยะเวลาเก็บ |
|---|---|---|---|
| อีเมล Google (@up.ac.th) | ใช้เข้าสู่ระบบและกำหนดบทบาท | ระบบ + ADMIN | จนถูกลบ |
| ชื่อ-นามสกุล (จาก Google) | แสดงเป็นผู้จัดทำ/ผู้ใช้ | ทุกคน (บนหน้าเว็บ) | จนถูกลบ |
| studentId | เก็บเพื่อการตรวจสอบ/สถิติภายใน | เฉพาะ ADMIN / DEPT_MEMBER (ไม่เปิด public) | จนถูกลบ |
| อีเมลอาจารย์ที่ปรึกษา | เก็บเพื่อการจัดการ | เฉพาะ ADMIN | จนถูกลบ |
| IP address (แฮช SHA-256) | ใช้ใน DownloadLog เพื่อป้องกันการดาวน์โหลดหลายครั้ง | เฉพาะ ADMIN | 1 ปี |
| บันทึกรายการโปรด / การค้นหาที่บันทึก | ส่วนตัวของผู้ใช้ | เฉพาะผู้เข้าใช้ | จนถูกลบ |

### หลักการ
1. **studentId ไม่เคยแสดง** บนหน้าเว็บใด ๆ หรือ API response ใด ๆ เลย
2. **อีเมลอาจารย์/นิสิตไม่เปิดเผย** แต่ละกรณีต้องผ่านการพิจารณา
3. **IP address ถูกแฮช** (SHA-256) ก่อนบันทึก ไม่มีการเก็บ IP ดิบ
4. **ข้อมูลส่วนตัวของผู้ใช้** (บันทึกรายการโปรด, การค้นหา) เข้าถึงได้เฉพาะตัวเอง

### การเข้าถึงข้อมูล
- **PUBLIC**: ทุกคน (รวมผู้เยี่ยมชมโดยไม่มีการลงชื่อเข้าสู่ระบบ)
- **AUTHENTICATED**: ผู้ใช้ที่ลงชื่อเข้าสู่ระบบด้วย Google @up.ac.th
- **DEPT_MEMBER**: นิสิต/บุคลากรที่ถูกยืนยัน (กำหนดอัตโนมัติเมื่อเข้าสู่ระบบ)
- **ADMIN**: ผู้ดูแลระบบ (เท่านั้นสามารถเข้าถึง studentId, อีเมล, และข้อมูลดาวน์โหลด)

### การจัดการขอบคุณภาพข้อมูล
- นิสิตสามารถขอดู/แก้ไขข้อมูลส่วนตัวของตนเองได้ที่ `/my/profile` (ภายหลัง)
- นิสิตสามารถขอลบบัญชีผู้ใช้ได้โดยติดต่อผู้ดูแลระบบ

### การจัดการข้อมูลเลิกใช้ (Data Retention)
- ข้อมูลภาคนิพนธ์: เก็บจนกว่าจะถูกลบโดย ADMIN
- DownloadLog: เก็บ 1 ปี แล้วลบอัตโนมัติ
- บันทึกรายการโปรด/การค้นหา: เก็บจนกว่าผู้ใช้จะลบเอง

### การจัดการขอบคุณภาพข้อมูล (Takedown Request)
ถ้าผู้ใช้ต้องการขอให้ระบบลบข้อมูลส่วนตัวหรือภาคนิพนธ์:
1. ติดต่ออาจารย์ที่ปรึกษาหรือผู้ดูแลระบบที่ `ADMIN_EMAIL`
2. ระบุชื่อภาคนิพนธ์และเหตุผลขอลบ
3. ผู้ดูแลระบบจะตรวจสอบและดำเนินการภายใน 7 วันทำการ
4. หลังจากลบแล้ว ระบบจะส่งอีเมลยืนยันการลบ

### ข้อความยินยอม (Consent Wording)
เมื่อนิสิตส่งภาคนิพนธ์ จะต้องยอมรับข้อความ:
> "ข้าพเด็กยินยอมให้ภาคนิพนธ์นี้เผยแพร่ในคลังภาคนิพนธ์ CS มหาวิทยาลัยพะเยา เป็นข้อมูลสาธารณะตามระดับการเข้าถึงที่เลือก และยินยอมให้ชื่อ-นามสกุลและอีเมลอาจารย์ที่ปรึกษาปรากฏบนหน้าเว็บ"

### ติดต่อ
- อีเมลผู้ดูแลระบบ: ตั้งค่าใน `ADMIN_EMAIL`
- นโยบายนี้อัปเดตล่าสุด: ดูที่ `/privacy` บนเว็บไซต์
