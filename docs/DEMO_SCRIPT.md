# docs/DEMO_SCRIPT.md
## สคริปต์สาธิต 5 นาที (Demo Script)

### นาทีที่ 1: หน้าแรก
- **เปิดเว็บ**: ไปที่ `http://localhost:3000`
- **พูด**: "นี่คือคลังภาคนิพนธ์ CS มหาวิทยาลัยพะเยา — สำหรับนิสิตที่กำลังมองหาหัวข้อวิจัย"
- **แสดง**: คาร์ดภาคนิพนธ์ล่าสุด, หมวดงานวิจัย, เทคโนโลยียอดนิยม
- **กด**: ลิงก์ **"ดูสถิติ"** → `/stats` (หน้าสาธารณะ)

### นาทีที่ 2: ค้นหาและกรอง
- **กด**: ปุ่ม **"ค้นหา"** หรือเข้า `/search`
- **พูด**: "ค้นหาด้วยภาษาไทยได้เลย — ระบบจะค้นหาจากชื่อเรื่อง, บทคัดย่อ, ผู้จัดทำ, อาจารย์, เทคโนโลยี"
- **สาธิต**:
  - พิมพ์คำว่า "machine learning" → ดูผลลัพธ์
  - กรองด้วย **ปีการศึกษา 2567**, **หมวดงานวิจัย**, **เทคโนโลยี**
  - เปลี่ยนเรียงลำดับเป็น **"ดาวน์โหลดมากสุด"**
- **กด**: **"บันทึกการค้นหา"** (ต้องเข้าสู่ระบบ) → ตั้งชื่อ "ML 2567"

### นาทีที่ 3: ตรวจสอบหัวข้อซ้ำ
- **กด**: ลิงก์ **"ตรวจสอบหัวข้อซ้ำ"** → `/check-topic`
- **พูด**: "นิสิตสามารถตรวจสอบว่าหัวข้อที่ต้องการทำเคยมีคนทำแล้วหรือไม่"
- **สาธิต**: วางชื่อเรื่อง เช่น "การพัฒนาเว็บไซต์" → ดูคะแนนความคล้าย + 10 อันดับแรก + แถบสี + คำเตือน

### นาทีที่ 4: ดูรายละเอียดและดาวน์โหลด
- **กด**: ที่การ์ดภาคนิพนธ์ → `/papers/[slug]`
- **พูด**: "ดูรายละเอียดได้ทั้งภาษาไทยและอังกฤษ"
- **สาธิต**:
  - แท็บ **ไทย / English**
  - **ดาวน์โหลด PDF** (ถ้าเป็น PUBLIC — กดได้เลย; ถ้า AUTHENTICATED — ต้องเข้าสู่ระบบ)
  - **ดูตัวอย่าง PDF** (ถ้ามีสิทธิ์)
  - **อ้างอิงงานวิจัยนี้** → คัดลอก APA 7 / IEEE / BibTeX / RIS หรือดาวน์โหลด .bib / .ris

### นาทีที่ 5: แดชบอร์ดผู้ดูแล (เฉพาะ ADMIN)
- **เข้าสู่ระบบ**: ใช้ Google @up.ac.th หรือบัญชี ADMIN
- **กด**: เมนู **"ผู้ดูแล"** → `/admin`
- **พูด**: "ผู้ดูแลสามารถจัดการภาคนิพนธ์, หมวด, เทคโนโลยี, อาจารย์, ผู้ใช้, และดูสถิติ"
- **สาธิต**:
  - **แดชบอร์ด**: KPI, แผนภูมิแท่ง/วงกลม/เส้น, ตารางอาจารย์
  - **เพิ่มภาคนิพนธ์**: กด **"เพิ่มภาคนิพนธ์"** → กรอกฟอร์ม → บันทึกเป็น DRAFT → ส่งเพื่อตรวจสอบ
  - **คิวตรวจสอบ**: `/admin/moderation` → อนุมัติ / ปฏิเสธพร้อมเหตุผล
  - **นำเข้าข้อมูล**: `/admin/import` → อัปโหลด CSV/XLSX → ตรวจสอบ → นำเข้า

### จบการสาธิต
- **พูด**: "ระบบพร้อมใช้งานแล้ว — สามารถนำไปติดตั้งบน Vercel + Neon ได้ทันที"
