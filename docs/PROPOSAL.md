# docs/PROPOSAL.md
## ปัญหา
ศูนย์ค้นหาโครงการวิจัยเก่าของนิสิต CS ที่มหาวิทยาลัยพะเยาไม่มีแหล่งข้อมูลศูนย์กลาง ทำให้ยากที่จะค้นพบโครงการที่เคยทำแล้ว หรือเทคโนโลยีที่ใช้

## วิธีแก้
สร้างเว็บแอปพลิเคชันดิจิทัลไลบรารีขนาดเล็ก เก็บโครงการวิจัยภาคนิพนธ์นักศึกษาปริญญาตรี CS มากขึ้น 5 ปี พร้อมค้นหา/กรองตามหัวข้อ/เทคโนโลยี/ปีการศึกษา

## ประโยชน์ต่อนิสิต / อาจารย์ / สาขา
- นิสิต: ค้นหาหัวข้อ/เทคโนโลยีที่เคยมีคนทำแล้ว ก่อนเลือกหัวข้อ พร้อมตรวจสอบความซ้ำ
- อาจารย์: ดูภาระงานและผลงานของนิสิตที่ปรึกษา
- สาขา: มีฐานข้อมูลผลงานอ้างอิงต่อหลักสูตรและการประเมินผล

## สิ่งที่ระบบทำได้ (Phase 1)
- ค้นหาและกรองภาคนิพนธ์ (รองรับภาษาไทย)
- หน้าดูรายละเอียดพร้อมแสดง title/abstract 兩語
- ดาวน์โหลด PDF ตามระดับการเข้าถึง (PUBLIC / AUTHENTICATED / DEPT_ONLY)
- แดชบอร์ดผู้ดูแล: เพิ่ม/แก้ไข/ลบ ภาคนิพนธ์ หมวด เทคโนโลยี อาจารย์ ผู้ใช้
- ตรวจสอบหัวข้อซ้ำ (similarity scoring)
- ระบบรักษาความเป็นส่วนตัวตาม PDPA (ไม่เปิด studentId / อีเมล)

## ค่าใช้จ่ายในการดูแล (free tiers)
- Vercel Hobby: ฟรี (เหมาะกับ traffic ระดับแภาควิชา)
- Neon Postgres: ฟรี 300 ชั่วโมง/เดือน และ 1 GB storage
- Google OAuth: ใช้งานฟรีภายใน @up.ac.th
- ไม่มีค่าใช้จ่ายซอฟต์แวร์ใด ๆ ในขั้นตอนนี้

## แผนการนำไปใช้
- Phase 1 (สมบูรณ์): ค้นหา + รายละเอียด + ดาวน์โหลด + แดชบอร์ดผู้ดูแล
- Phase 2 (สมบูรณ์): นำเข้า CSV จำนวนมาก, อิมโพรทข้อมูลจริง
- Later: นิสิตส่งโครงการเอง, SEO สำหรับ Google Scholar, OAI-PMH
