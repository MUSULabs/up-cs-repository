# docs/ADMIN_MANUAL.md
## คู่มือการใช้งานสำหรับผู้ดูแลระบบ (ADMIN / DEPT_MEMBER)

### 1. เข้าสู่ระบบ
- ไปที่ `/login`
- เข้าสู่ระบบด้วย:
  - **Google @up.ac.th** (จะได้รับบทบาท DEPT_MEMBER อัตโนมัติ)
  - หรือใช้บัญชีผู้ดูแล (ADMIN) ที่ตั้งไว้ใน `.env` (ADMIN_EMAIL / ADMIN_PASSWORD)
- หลังเข้าสู่ระบบ จะเห็นเมนูผู้ดูแลในหัวข้อด้านบน

### 2. จัดการภาคนิพนธ์
- ไปที่ `/admin/papers`
- รายการทั้งหมด (รวม DRAFT, PENDING, REJECTED, PUBLISHED) — สามารถกรองตามสถานะได้
- **เพิ่มใหม่**: กดปุ่ม **"เพิ่มภาคนิพนธ์"** → กรอกฟอร์ม (เหมือนฟอร์มผู้ดูแล)
  - ชื่อเรื่องไทย/อังกฤษ
  - บทคัดย่อไทย/อังกฤษ
  - ปีการศึกษา, ภาคเรียน
  - ผู้จัดทำ 1–3 คน (กรอกชื่อเท่านั้น)
  - อาจารย์ที่ปรึกษาหลัก / ร่วม (เลือกจากรายการ หรือเพิ่มใหม่ได้)
  - หมวดงานวิจัย, คำสำคัญ, เทคโนโลยี
  - ระดับการเข้าถึง (PUBLIC / AUTHENTICATED / DEPT_ONLY)
  - อัปโหลด PDF (ขนาด ≤ 10 MB, ต้องเป็น PDF จริง)
  - บันทึกเป็น **DRAFT** → แก้ไขได้หลายครั้ง
  - เมื่อพร้อม → กด **"ส่งเพื่อตรวจสอบ"** → สถานะจะเป็น **PENDING** (รอการอนุมัติ)
- **แก้ไข**: กดไอคอนดินสอที่แถวรายการ → แก้ไขได้เฉพาะเมื่อสถานะเป็น DRAFT หรือ PENDING (หลังอนุมัติแล้วแก้ไขไม่ได้)
- **ลบ**: กดไอคอนถังขยะ → ลบได้เฉพาะ DRAFT หรือ REJECTED
- **ดาวน์โหลด PDF**: กดไอคอนดาวน์โหลด (ตรวจสอบสิทธิ์แล้ว)

### 3. จัดการคำขอส่ง (เฉพาะ ADMIN)
- ไปที่ `/admin/moderation` — คิวรอการตรวจสอบ (เฉพาะ PENDING)
- รายการแต่ละรายการแสดง:
  - คอลัมน์ซ้าย: ข้อมูลต้นฉบับที่นิสิตส่งมา (ไม่สามารถแก้ไขได้)
  - คอลัมน์ขวา: ฟอร์มแก้ไข (เริ่มต้นเป็นค่าต้นฉบับ)
- การกระทำ:
  - **อนุมัติ** → สถานะจะเป็น **PUBLISHED** ทันที
  - **อนุมัติพร้อมแก้ไข** → แก้ไขฟอร์มด้านขวาแล้วกดปุ่มนี้ → จะบันทึกการแก้ไขและเผยแพร่
  - **ปฏิเสธพร้อมเหตุผล** → พิมพ์เหตุผลเป็นภาษาไทย → สถานะจะเป็น **REJECTED** และนิสิตจะเห็นเหตุผลใน `/my/submissions`
- หลังการกระทำ รายการจะหายออกจากคิว

### 4. จัดการหมวดงานวิจัย / เทคโนโลยี / คำสำคัญ
- ไปที่ `/admin/areas`, `/admin/technologies`, `/admin/keywords`
- เพิ่ม/แก้ไข/ลบได้ตามต้องการ
- ชื่อต้องเป็นภาษาไทย (ยกเว้นเทคโนโลยีบางอย่างอาจเป็นภาษาอังกฤษ)

### 5. จัดการอาจารย์ที่ปรึกษา
- ไปที่ `/admin/advisors`
- เพิ่มอาจารย์ใหม่: กรอกคำนำหน้า (ผศ. / ดร. / ฯลฯ), ชื่อจริงไทย, นามสกุลไทย
- ระบบจะแสดงชื่อเต็มในฟอร์มเลือกอาจารย์โดยอัตโนมัติ

### 6. จัดการผู้ใช้ (เฉพาะ ADMIN)
- ไปที่ `/admin/users`
- ดูรายการผู้ใช้ที่เข้าสู่ระบบผ่าน Google @up.ac.th
- เปลี่ยนบทบาท: VIEWER → DEPT_MEMBER → ADMIN (เฉพาะ ADMIN ทำได้)
- หมายเหตุ: บทบาท DEPT_MEMBER จะถูกกำหนดโดยอัตโนมัติเมื่อเข้าสู่ระบบด้วยอีเมล @up.ac.th แต่ ADMIN สามารถเพิ่มบทบาทให้สูงขึ้นได้

### 7. นำเข้าข้อมูลจำนวนมาก (CSV/XLSX)
- ไปที่ `/admin/import`
- ดาวน์โหลด **เทมเพลต** ที่ปุ่มด้านบน (มีหัวเป็นภาษาไทย)
- เตรียมไฟล์ .csv หรือ .xlsx ตามเทมเพลต:
  - ชื่อเรื่องภาษาไทย, ชื่อเรื่องภาษาอังกฤษ
  - บทคัดย่อภาษาไทย, บทคัดย่อภาษาอังกฤษ
  - ปีการศึกษา, ภาคเรียน
  - ผู้จัดทำ1..3, อาจารย์ที่ปรึกษาหลัก, อาจารย์ที่ปรึกษาร่วม
  - หมวดงานวิจัย, คำสำคัญ, เทคโนโลยี
  - ระดับการเข้าถึง (PUBLIC / AUTHENTICATED / DEPT_ONLY)
- อัปโหลดไฟล์ → ระบบจะแสดงหน้าตรวจสอบแถวข้อมูล:
  - **VALID**: ผ่านการตรวจสอบทั้งหมด
  - **WARNING**: มีข้อผิดพลาดเล็กน้อย (เช่น ชื่ออาจารย์ไม่ตรง แต่ระบบเสนอให้สร้างใหม่)
  - **ERROR**: ไม่สามารถนำเข้าได้ (เช่น ขาดฟิลด์บังคับ)
- ตรวจสอบแต่ละแถว → ตัดสินใจสร้างรายการใหม่หรือไม่ (กรณีที่ไม่พบในฐานข้อมูล)
- ตรวจสอบซ้ำโดยชื่อเรื่อง: ระบบจะแจ้งหากพบชื่อเรื่องคล้ายกัน ให้เลือกข้ามหรือทับ
- กด **"นำเข้า"** → ระบบจะทำงานภายในธุรกรรมและแสดงสรุปผล (สร้าง / ข้าม / ล้มเหลว)
- ดาวน์โหลดรายงานข้อผิดพลาด CSV ได้หากมีแถวล้มเหลว

### 8. ส่งออกข้อมูลทั้งหมด
- ไปที่ `/admin/export`
- กดปุ่ม **"ส่งออกเป็น XLSX"** → จะดาวน์โหลดไฟล์ที่มีภาคนิพนธ์ทั้งหมดที่มีสถานะ PUBLISHED

### 9. ดาวน์โหลดเทมเพลต
- อยู่ในหน้า `/admin/import` → ปุ่ม **"ดาวน์โหลดเทมเพลต"** จะให้ไฟล์ .xlsx พร้อมหัวเป็นภาษาไทย

### 10. การตั้งค่าระบบ (ไฟล์ .env)
- ไม่ต้องแก้ไขบ่อย ๆ แต่หากต้องการเปลี่ยน:
  - `ADMIN_EMAIL`, `ADMIN_PASSWORD`: บัญชีผู้ดูแลสำรอง
  - `ALLOWED_EMAIL_DOMAIN`: ค่าเริ่มต้น `up.ac.th` (จำกัดการเข้าสู่ระบบด้วย Google เฉพาะโดเมนนี้)
  - `BLOB_READ_WRITE_TOKEN`: หากใช้การจัดเก็บไฟล์ใน Vercel Blob (ตั้งค่า `STORAGE_DRIVER=blob`)
  - `DATABASE_URL`: เชื่อมต่อกับฐานข้อมูล PostgreSQL (Neon)
  - `AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`: สำหรับ Auth.js (ตั้งค่าแล้วในขั้นตอนติดตั้ง)
