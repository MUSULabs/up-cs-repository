# docs/USER_MANUAL.md
## คู่มือการใช้งานสำหรับนิสิต

### 1. ค้นหาภาคนิพนธ์
- เข้าไปที่หน้าแรก → กด **"ค้นหา"** หรือเข้า `/search` โดยตรง
- พิมพ์คำค้นหาในช่อง **"คำค้นหา"** (ค้นในชื่อเรื่อง/บทคัดย่อ/ผู้จัดทำ/อาจารย์/เทคโนโลยี)
- ใช้ตัวกรองด้านข้าง:
  - **ปีการศึกษา** (เช่น 2567)
  - **ภาคเรียน** (1/2/ฤดูร้อน)
  - **หมวดงานวิจัย** (เลือกหลายหมวดได้)
  - **เทคโนโลยี** (เลือกหลายตัวได้)
  - **ระดับการเข้าถึง** (PUBLIC / AUTHENTICATED / DEPT_ONLY)
- เรียงลำดับ: ความเกี่ยวข้อง / ใหม่สุด / เก่าสุด / ดูมากสุด / ดาวน์โหลดมากสุด
- กด **"ค้นหา"** หรือกด Enter — URL จะอัปเดตอัตโนมัติ สามารถแชร์ลิงก์ได้

![หน้าค้นหา](screenshots/search.png)

### 2. ตรวจสอบหัวข้อซ้ำ
- เข้า `/check-topic`
- วาง **ชื่อเรื่องภาษาไทย** ที่เสนอ (และคำอธิบายสั้น ๆ ถ้ามี)
- กด **"ตรวจสอบ"** — ระบบจะคำนวณคะแนนความคล้ายกับภาคนิพนธ์ที่เผยแพร่แล้ว
- ดู **10 อันดับแรก** พร้อมแถบสี:
  - 🔴 **สูงมาก (>70)**: "หัวข้อนี้เคยมีคนทำแล้ว ควรปรับมุมมอง"
  - 🟡 **ปานกลาง (40–70)**: "มีงานใกล้เคียง ควรอ่านก่อน"
  - 🟢 **ต่ำ (<40)**: "ยังไม่พบงานที่ใกล้เคียง"
- ดูรายละเอียด: ปี, อาจารย์, คำที่ตรงกัน, เทคโนโลยีที่ตรงกัน

![หน้าตรวจสอบหัวข้อ](screenshots/check-topic.png)

### 3. ดูรายละเอียดและดาวน์โหลด
- กดที่การ์ดภาคนิพนธ์ → เข้าหน้า `/papers/[slug]`
- แท็บ **ไทย / English** สลับ title/abstract
- เมตาดาต้า: ปี, ภาคเรียน, ผู้จัดทำ, อาจารย์, หมวด, คำสำคัญ, เทคโนโลยี, จำนวนหน้า
- **ดาวน์โหลด PDF**:
  - PUBLIC: กดได้เลย
  - AUTHENTICATED: ต้องเข้าสู่ระบบ (Google @up.ac.th)
  - DEPT_ONLY: ต้องเป็น DEPT_MEMBER หรือ ADMIN
- **ดูตัวอย่าง PDF**: กด **"ดูตัวอย่าง"** (ถ้ามีสิทธิ์)
- **อ้างอิงงานวิจัยนี้**: กดเพื่อคัดลอก APA 7 / IEEE / BibTeX / RIS หรือดาวน์โหลด .bib / .ris

![หน้ารายละเอียด](screenshots/paper-detail.png)

### 4. บันทึกรายการโปรด (ต้องเข้าสู่ระบบ)
- หน้าผลค้นหา/รายละเอียด: กดไอคอน **หัวใจ/บุ๊กมาร์ก**
- ไป `/my/bookmarks` ดูรายการที่บันทึก พร้อมเขียนโน้ตส่วนตัว
- ส่งออกเป็น `.bib` ได้

### 5. บันทึกการค้นหา (ต้องเข้าสู่ระบบ)
- หน้า `/search` หลังกรองแล้ว → กด **"บันทึกการค้นหา"** ตั้งชื่อ
- ไป `/my/searches` คลิกเพื่อรันซ้ำได้ทันที

### 6. เปรียบเทียบภาคนิพนธ์ (ต้องเข้าสู่ระบบ)
- หน้า `/search` → เลือกสูงสุด 3 รายการ → กด **"เปรียบเทียบ"**
- ไป `/compare` ดูตารางคัดกรอง: ปี, อาจารย์, หมวด, เทคโนโลยี, หน้า, บทคัดย่อ — ไฮไลท์ความต่าง
